# arcade-racer

Аркадный гоночный чемпионат: Three.js (WebGPU с фоллбэком на WebGL2) + Rapier.

Игра переносится с отлаженного WebGL-прототипа: прототип фиксирует дизайн и правила
(механика газа, камера, форма трасс, тайминги, очки), здесь меняется «низ» — рендер и физика.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + сборка в dist/
npm run typecheck
```

Параметры в адресной строке: `?webgl` принудительно включает WebGL2-бэкенд (проверка фоллбэка),
`?physics` рисует каркас коллайдеров поверх сцены.

## Что уже есть (M0–M3)

- **M0** — Vite + TypeScript, `WebGPURenderer` с фоллбэком на WebGL2, фиксированный игровой
  цикл (физика 60 Гц + интерполяция рендера), статичная изометрическая ортокамера
  с автоподгонкой под границы трассы.
- **M1** — построение геометрии всех пяти трасс (порт `roundedPath`/`resampleClosed` и данных
  `TRACKS` из прототипа), low-poly материалы с плоским шейдингом, одна машинка на стартовой
  сетке без физики.

- **M2** — физика Rapier: raycast-подвеска, настоящие стены по кромкам дороги, газ через
  частоту нажатий (модель «оборотов» с пиком момента на ~10 нажатиях в секунду), руль,
  тормоз, задний ход, ручник. Вся геймлогика идёт в фиксированном тике, рендер интерполирует.

- **M3** — занос: передняя ось держит, задняя срывается, ручник роняет её сцепление ещё сильнее.
  Сверху стоит явный потолок на угол заноса, привязанный к рулю: держишь поворот или ловишь
  занос контррулением — занос живёт, выровнял руль — машина возвращается на курс.
  Развернуть машину полностью нельзя ни газом, ни ручником.

Управление: `↑`/`W` — газ (жать часто, не удерживать), `←`/`→` — руль, `↓` — тормоз и задний ход,
`Пробел` — ручник, `R` — на старт, `1`…`5` — трасса.
Препятствий, ИИ и правил пока нет — это M4 и дальше.

## Структура

```
src/
├─ constants.ts        числа из прототипа: баланс газа, правила уик-энда, габариты
├─ main.ts             bootstrap и сборка сцены
├─ core/
│  ├─ Loop.ts          accumulator: фиксированный шаг + интерполяция
│  ├─ Input.ts         клавиатура -> PlayerInput, общий с ИИ интерфейс усилий
│  └─ rng.ts           детерминированный ГПСЧ для расстановки декора
├─ physics/
│  ├─ World.ts         мир Rapier, земля, фиксированный шаг
│  ├─ Vehicle.ts       raycast-подвеска, газ/руль/тормоз, телеметрия колёс
│  ├─ Barriers.ts      стены по кромкам дороги из тех же нормалей
│  └─ DebugRender.ts   каркас коллайдеров (?physics)
├─ render/
│  ├─ Renderer.ts      выбор бэкенда, проверка боем, свет и тени
│  ├─ Camera.ts        статичная изометрия, подгонка под трассу
│  ├─ materials.ts     low-poly материалы, палитра
│  └─ Car.ts           визуальная модель машинки
├─ track/
│  ├─ tracks.ts        данные трасс (копия TRACKS)
│  ├─ path.ts          осевая линия, касательные, профиль кривизны
│  └─ buildTrack.ts    полотно, кромки, старт/финиш, декор
├─ game/
│  └─ grid.ts          места на стартовой сетке
└─ ui/
   └─ debug.ts         отладочная панель каркаса
```
