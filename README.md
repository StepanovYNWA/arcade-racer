# arcade-racer

Аркадный гоночный чемпионат: Three.js (WebGPU с фоллбэком на WebGL2) + Rapier.

Игра переносится с отлаженного WebGL-прототипа: прототип фиксирует дизайн и правила
(механика газа, камера, форма трасс, тайминги, очки), здесь меняется «низ» — рендер и физика.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + сборка в dist/
npm run typecheck
```

`?webgl` в адресной строке принудительно включает WebGL2-бэкенд — так проверяется фоллбэк.

## Что уже есть (M0–M1)

- **M0** — Vite + TypeScript, `WebGPURenderer` с фоллбэком на WebGL2, фиксированный игровой
  цикл (физика 60 Гц + интерполяция рендера), статичная изометрическая ортокамера
  с автоподгонкой под границы трассы.
- **M1** — построение геометрии всех пяти трасс (порт `roundedPath`/`resampleClosed` и данных
  `TRACKS` из прототипа), low-poly материалы с плоским шейдингом, одна машинка на стартовой
  сетке без физики.

Клавиши `1`…`5` переключают трассу. Управления и физики пока нет — это M2 и дальше.

## Структура

```
src/
├─ constants.ts        числа из прототипа: баланс газа, правила уик-энда, габариты
├─ main.ts             bootstrap и сборка сцены
├─ core/
│  ├─ Loop.ts          accumulator: фиксированный шаг + интерполяция
│  └─ rng.ts           детерминированный ГПСЧ для расстановки декора
├─ render/
│  ├─ Renderer.ts      выбор бэкенда, проверка боем, свет и тени
│  ├─ Camera.ts        статичная изометрия, подгонка под трассу
│  ├─ materials.ts     low-poly материалы, палитра
│  └─ Car.ts           визуальная модель машинки
├─ track/
│  ├─ tracks.ts        данные трасс (копия TRACKS)
│  ├─ path.ts          осевая линия, касательные, профиль кривизны
│  └─ buildTrack.ts    полотно, кромки, старт/финиш, декор
├─ game/
│  └─ grid.ts          места на стартовой сетке
└─ ui/
   └─ debug.ts         отладочная панель каркаса
```
